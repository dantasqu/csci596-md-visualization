## What the course asks for

| Requirement | Detail | How this project addresses it |
|---|---|---|
| Topic discussion | Discuss and agree on the topic with the instructor during office hours by **November 20, 2026** | This repository provides a concrete MD visualization topic to discuss; it does not claim instructor approval |
| Brief class presentation | Approximately **one minute**, on **November 30 or December 2, 2026** | [`PRESENTATION.md`](../PRESENTATION.md) provides a timed script and GitHub walkthrough |
| Presentation visual aid | Show the preliminary **GitHub repository**, outlining the problem, methods, and expected results | README gives a concise problem/method/results narrative with an animation and plot |
| Final project | A project related to simulations, parallel computing, or visualization; programming and proposal routes are offered | This is a programming project extending parallel MD and scientific visualization |
| Final submission | Create the project repository by **December 11, 2026** and submit its **URL to Brightspace** | The repository holds source, data, results, verification, and the written explanation; the student submits the URL separately |

The instructor's general final-project notes describe a **written report in the repository plus a presentation**. They emphasize communicating the problem, finding, and significance. The README is the concise entry point; [`METHODS_AND_RESULTS.md`](METHODS_AND_RESULTS.md) is the detailed report.

Some older lecture slides retain dates from previous years. The dates above use the **Fall 2026 handout and current course page**. Neither source inspected assigns Daniela an individual presentation slot. No Brightspace submission or message to the instructor is made by creating this repository.

The instructor's [AI poster-coaching lecture](https://github.com/aiichironakano/aiichironakano.Github.io/blob/master/cs596/AICoach.pdf) contains additional communication advice; its longer-pitch and poster examples do not replace the one-minute requirement in the current course handout.
